## 2. Linux: подтверждённые дескрипторы (#17, D630)

**Mobile Mode** — «Analog Stereo Duplex»:

```
Playback:  2 канала, S32_LE, 44100/48000, FL FR
Capture:   2 канала, S32_LE, 44100/48000, FL FR
```

**Live Streaming / Pro Audio** — «Multi-Channel Duplex»:

```
Playback: 10 каналов, S32_LE, 44100/48000/88200/96000
          Channel map: FL FR FC LFE RL RR FLC FRC RC SL
          (это ЛОЖНАЯ surround-карта, подставленная ядром —
           на самом деле 5 независимых стерео-шин)
Capture:  16 каналов, S32_LE, 44100/48000/88200/96000
```

### Карта каналов захвата (проверена на слух, #17)

```
AUX0/1   -> Analog 1/2 (IN1: MIC1 | MIC 3.5 | MIC-HP; IN2: MIC2)
AUX2/3   -> AUX IN
AUX4/5   -> Bluetooth IN
AUX6/7   -> Mobile IN (OTG)
AUX8/9   -> Loopback 1/2
AUX10/11 -> Loopback 3/4
AUX12/13 -> Loopback 5/6
AUX14/15 -> Loopback 7/8
```

**Совпадает** с UCM-профилем и нашими замерами.

### Прочее из #17

- **Vendor USB: Thesycon Systemsoftware & Consulting GmbH**
- **Эффекты (FX) доступны только в Mobile и Live Streaming**
- **10-полосный PEQ для наушников — только в Pro Audio**
- Пульт на **31 кнопку**
- MCC обязателен для: обновления прошивки, настройки Bluetooth,
  питания портов OTG/USB-C, автовключения, EQ, авто-гейна,
  эффектов, микшера
- Версия автора: HW V1.00, **FW V87.05.45.48.37**, SW V1.8.0

## 3. Процедура factory reset (#32) — ВАЖНО

> «factory reset» — не настоящий сброс, часть настроек остаётся.

1. Выключить (долгое нажатие может не работать при зависании;
   помогает подача питания на порт Charge).
2. Подождать ≥5 с, зажать **обе кнопки громкости HP** и включить.
   Должны загореться все 4 ряда LED.
3. Дать загрузиться ~10 с.
4. Выключить, зажать **SEL** и включить. Загорятся 2 огня — это
   Mobile Mode. Нажать SEL дважды → 6 огней = Pro Mode.
5. Зажать питание до полной загрузки.

**Последствия сброса (важно для нашего сервиса):**
- MIC1, MIC2, AUX корректно мапятся на USB 1,2,3,4;
- **HP out = микс четырёх входов** (1+3 влево, 2+4 вправо);
- **питание USB-C сбрасывается в «charging»** — телефон ругается;
- яркость дисплея сбрасывается;
- **OTG получает моно-микс**.

## 4. Баги прошивки, о которых сообщал пользователь (#32)

Это **прямые сведения о поведении прошивки** — полезно при реверсе:

- **Реверб и шумоподавление остаются доступны в Pro-режиме**, хотя
  должны быть отключены (легко включить кнопками случайно).
- **Factory reset не сбрасывает все настройки** (проверяется по P48).
- **Устройство зависает** иногда без подключения к компьютеру.
- **В Pro-режиме карта не видит микрофонный вход, пока не подключён
  USB-C.**

Отсюда важное: **в прошивке есть расхождение между тем, что заявлено,
и тем, что реализовано.** Это подтверждает, что эффекты управляются
кнопками на устройстве, а не только из MCC.

## 5. Гейн-стейджинг: внутренний переключатель +19 дБ (#34)

> «the unit switches/pads internally between +18 and +19dB gain on the
> mic input»

То есть **на границе 19 дБ меняется сигнальный путь** в аналоге.
Это подтверждает более раннее наблюдение из первой ветки.

**Практическое следствие:** «0 дБ гейна» не означает «нет усиления» —
внутри есть переключение диапазона. При замерах это надо учитывать.

Также: **изменение гейна ниже 19 дБ не даёт headroom** — цифровые
результаты идентичны при любом значении. То есть гейн работает как
нормализация, а не как аналоговое усиление (кроме переключения на 19).

## 6. Питание и порты (#17, #29, #32)

- Порт **Charge** — только зарядка M62.
- Порт **USB-C** — данные + настраиваемое питание
  (charge / discharge / off).
- Порт **OTG** — 2 канала, настраиваемое питание.
- Одновременно заряжаться и разряжаться можно.
- Заряд до 5 В / 2,5 А (без PD), разряд 5 В / 1 А.

### Подтверждено

| факт | источник |
|---|---|
| XMOS XU316 внутри | #37 (разборка) |
| 2× ES9821Q АЦП | #37 |
| AK7604 в тракте выхода | #37 |

| карта каналов захвата | #17 (измерено) |
| эффекты только Mobile/Live | #17, #30 |
| PEQ наушников только Pro | #17 |
| гейн-переключатель +19 дБ | #34 |
| батарея заменяемая | #37 |

### Новое для нас

1. **AK7604 — аудио-процессор, а не просто ЦАП.** Часть DSP может
   быть в нём, а не в XMOS. Это меняет оценку «добавить эффекты».
2. **Процедура factory reset** — можно вернуть карту в известное
   состояние без MCC.
3. **Баги прошивки** — реверб и NC доступны в Pro через кнопки,
   хотя не должны. Значит управление эффектами есть на устройстве.
4. **STM32G070R** — отдельный контроллер для кнопок/LED. Прошивка
   XMOS — не единственная.

### Чего по-прежнему нет

- модель QSPI-флеша;
- распиновка JTAG/UART;
- полный дамп прошивки.
