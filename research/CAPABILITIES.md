## Часть 1. Что можем СЕЙЧАС

### 1.1 Управление картой из браузера — полностью

Веб-клиент работает без установки ПО, через WebHID. Проверено на
живой карте.

| группа | что именно | проверено |
|---|---|---|
| **Выходы** | громкость HP, mute HP, mute OTG, кнопка «Заглушить» | на карте |
| **Усиление входов** | IN1, IN2, AUX, BT, OTG IN — в правильных дБ | шкалы сверены с драйвером ядра |
| **48 В** | IN1 и IN2, с подтверждением | на карте |
| **Реверб** | тип (Bypass/Studio/Live/Hall) + dry-wet, room, decay, width | на карте |
| **Компрессор** | 6 параметров | на карте |
| **EQ входов** | IN1 и IN2, 4 полосы × 5 свойств (вкл, тип, gain, частота, Q) | **5/5 на карте** |
| **EQ наушников** | 10 полос × 2 канала (только Prof) | **8/8 на карте** |
| **Микшер** | 5 шин × 11 источников | запись работает, чтение невозможно |
| **Mutes** | 7 переключателей входов и выходов | mute выходов читается |
| **Loopback** | 4 возврата: гейн + источник | запись работает |
| **Сцены** | сохранить/загрузить/удалить | 35/35 тестов |
| **Батарея** | заряд в процентах (`0x11:0x18`) | на карте: 94% |
| **Режим** | Mobile / Live / Prof — мгновенно, из ответа handshake | на карте |
| **Селекторы источников** | 6 штук, 14 пунктов | запись работает |

### 1.2 Понимание устройства — полное

| что знаем | откуда |
|---|---|
| **Процессор DSP** | XMOS XU316 (xCore XS3) — корпус + профиль + разборка |
| **АЦП** | 2× ESS ES9821Q = 4 канала оцифровки — разборка |
| **Выход** | AKM AK7604 (аудио-процессор) — разборка |
| **Управление** | STM32G070R (кнопки, LED, питание) — разборка |
| **Батарея** | 5000 мА·ч, заменяемая — разборка |
| **USB-порты** | 3 шт: multichannel / OTG(2 канала) / заряд |
| **Каналы** | 10 playback = 5 стерео-шин; 16 capture |
| **Режимы** | Mobile / Live / Prof, различаются bcdDevice |
| **Протокол** | кадр 15 байт, HID interface 4, CRC не проверяется |

Всё это **независимо подтверждено** опубликованным драйвером ядра
(2280 строк) и UCM-профилем.

## Часть 2. Что НЕДОСТУПНО и почему

### 2.1 Технически невозможно через HID

| что | почему | можно ли обойти |
|---|---|---|
| **Прочитать микшер** | карта не отдаёт его: 1600 записей, 0 чтений | нет — свойство протокола |
| **Прочитать loopback** | то же | нет |
| **Прочитать ducking** | то же | нет |
| **Прочитать селекторы источников** | карта их не сообщает | нет |
| **Подтвердить запись в тишине** | метры приходят только при звуке | только при звуке |
| **`Mic Capture Switch`** | это UAC-контрол, не HID-тег | через ОС, не из браузера |
| **Sample rate / buffer** | настройки ОС, реестр защищён | чтение через агент |

**Следствие для UI:** там, где карта не отдаёт состояние, показываем
нашу модель (`localStorage`) и честно предупреждаем. Так же устроен
сам MCC (держит микшер в workspace-INI).

### 2.2 Требует физического доступа (разборка не нужна, но нужны действия)

| что | что нужно |
|---|---|
| **Дамп флеш-памяти** | знать корпус флеша + CH341A/прищепка, либо XTAG4 |
| **Отладка прошивки** | JTAG (XTAG4) + распиновка |
| **UART-консоль** | найти пятачки TX/RX на плате |

**Разбирать карту не обязательно** для дампа флеша — прищепка
цепляется снаружи. Но **корпус флеша неизвестен**: в списке разборки
его нет, а на фото он выглядит многолапым, а не SOIC-8.

### 2.3 Требует денег

| покупка | цена | что даёт |
|---|---|---|
| CH341A + прищепка | ~500 ₽ | дамп флеша (если корпус SOIC-8) |
| XTAG4 (XMOS) | ~$100 | дамп флеша + отладка + JTAG |
| Вторая карта | ~$250 | безопасность экспериментов |

### 2.4 Не решено, но не блокирует

| вопрос | состояние |
|---|---|
| Есть ли у M62 экспандер | кнопка EXP в MCC есть, но общая с KB22 — не доказано |
| Где именно живут эффекты | возможно, не в XMOS, а в AK7604 |
| Что под белым экраном | слепая зона, возможно Bluetooth |

## Часть 3. Про добавление новых эффектов

Главный вопрос, который ставился.

### Что установлено

- **Delay** — есть у KB22, у M62 идентификаторов нет. Вероятно,
  отсутствует.
- **Expander** — не доказано ни в одну сторону.
- **AK7604** — аудио-процессор с собственным DSP. **Часть эффектов
  может быть в нём**, а не в XMOS. Это меняет оценку.

### Оценка усилий

| вариант | усилия | риск | реальность |
|---|---|---|---|
| Добавить эффект в прошивку XMOS, сохранив родные | месяцы | кирпич | маловероятно |
| Своя прошивка на XMOS вместо родной | недели-месяцы | кирпич | **свои эффекты, БЕЗ родных** |
| Настроить AK7604 по I²C | неизвестно | средний | возможно, если DSP там |
| **Эффекты в браузере (Web Audio)** | дни | нет | **работает сразу** |

### Честный вывод

**Добавить эффект в саму карту — это проект уровня «своя прошивка на
XMOS»**, а не правка строки. Причины:

1. Нужно понять DSP-конвейер в дизассемблере — работа на недели.
2. XMOS xCORE многопоточный: эффекты распределены по «логическим
   ядрам», у каждого свой бюджет реального времени.
3. Пересборка образа требует XTC Tools и понимания таймингов.
4. Запись через DFU — риск кирпича, нужна вторая карта.
5. Родные эффекты (реверб, NR, компрессор) при этом **потеряются**.

**Практичный путь: эффекты на стороне ПК/браузера.** Карта отдаёт
10 каналов playback и 16 capture — обрабатывать их можно где угодно
через Web Audio API. Нет риска, нет ограничений прошивки, работает
сразу.

## Часть 5. Что делать дальше

### Без вложений и риска

1. **Разбирать прошивку в Ghidra** — данные уже есть, нужен только
   труд. Найти точки входа, разметить функции, найти таблицы DSP.
2. **Проверить гипотезу про AK7604** — поискать в прошивке обращения
   к его I²C-регистрам. Если эффекты там, это меняет всю картину.
3. **Проверить экспандер** — записать теги `0x44:0x06/07` в Live и
   посмотреть, меняются ли метры.

### Если готовы на малые траты

4. **CH341A (~500 ₽)** — но сначала надо понять, какой корпус у
   флеша. Без разборки это можно определить только по фото лучшего
   качества.

### Если хочется эффектов быстро

5. **Web Audio в браузере** — delay, экспандер, что угодно, без
   вмешательства в карту.
