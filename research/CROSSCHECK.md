Цель: проверить, **не противоречат ли данные** из workspace-файла и из

## 2. Решающий тест GAIN

1. Файл: `Input_IN1.GAIN = 43`.
2. HID до действия: `0x21:0x04` **не приходил** (но это значит лишь, что
   устройство не отдаёт его без запроса).
3. Перетащил dial GAIN IN1 мышью (с DPI-коррекцией 1.75).
4. После:
   - файл: `GAIN = 49`
   - HID: `0x21:0x04 = 49`

**Оба канала синхронны.** Значит `Input_IN1.GAIN` в файле и
`0x21:0x04` в HID — это **один и тот же параметр**.

## 5. КОМПРЕССОР И DUCKING: почему не пришли в HID

При чтении с устройства `0x43` (ducking) и `0x46` (компрессор)
**не появились** — были только метры `0x46:0x09/0x0a`.

Открытие панели эффектов в UI (`MORE`) **не помогло** — теги не пришли.

**Возможные причины (не проверены):**
1. Компрессор выключен — устройство не отдаёт его параметры.
2. Они приходят только при явном изменении.
3. Нужен другой запрос, а не ANNOUNCE.

**Что точно известно:** в файле `[Compressor]` содержит
`Switch=true`, `Threshold=-18`, `Ratio=4`, `Attack=5`, `Release=200`,
`Gain=0`, `Mix=100` — то есть значения есть, но через HID их не получить.

**Практический вывод:** компрессор и ducking читать **из файла**,
а не из HID.

## 6. ЧТО ЭТО ЗНАЧИТ ДЛЯ БЕКЕНДА

Правильная архитектура:

```
чтение состояния:
  ├─ HID   -> метры, джеки, версия, настройки устройства, счётчик
  └─ файл  -> микшер, EQ, 48V, MIC, loopback, outputs, компрессор, ducking

запись:
  ├─ HID   -> громкости, селекторы, настройки (0x11), FX-уровни
  └─ UI    -> всё остальное (через UIAutomation MCC)
```

**Нельзя** пытаться получить микшер из HID — его там нет.
**Нельзя** получить компрессор из HID — его там нет (по крайней мере
без дополнительных условий).

## 7. EQ: ГДЕ ОН НА САМОМ ДЕЛЕ

### 7.1 В Live streaming mode EQ НЕДОСТУПЕН

Проверено:
- `EQ_IN1.Switch` в файле = 0, кнопки включения в UI не находится
- блоки `0x91..0x94` в HID **не приходят никогда**
- теги `0x9b:0x0f/0x10/0x12/0x13` **не приходят**

### 7.2 В Pro audio mode EQ_HP ЕСТЬ, но только в файле

### 7.4 Итог по EQ

| | доступно | откуда |
|---|---|---|
| EQ_IN1 / EQ_IN2 (4 полосы) | **только в файле**, Live-режим | `[EQ_INx]` |
| EQ_HP (до 10 полос) | **только в файле**, Pro-режим | `[EQ_HP]` |
| Через HID | **недоступно** | — |

**Управлять EQ можно только через UI MCC** (UIAutomation), не через HID.
