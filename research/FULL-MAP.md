# ПОЛНАЯ КАРТА ПАРАМЕТРОВ M62 — снята перехватом старта MCC

**Метод:** слушатель HID (только чтение) запущен, затем M Control Center
принудительно закрыт и открыт заново. MCC при инициализации отправляет
своё состояние целиком — слушатель поймал всё.

Дата: 2026-11-07. Лог: `research/sessions/restart-capture.jsonl`.
**В устройство я не писал. Писал MCC.**

Получено: **92 не-метровых параметра**, 18 метро-адресов.

---

## 1. ГЛАВНОЕ: EQ найден и подтверждён

В прошлый раз я не нашёл EQ, потому что страницы EQ нет в UI в текущем режиме.
Но MCC **шлёт EQ-теги при старте** — значит они рабочие:

| тег | значение при старте | смысл |
|---|---|---|
| `0x9b:0x0f` | 0 | **EQ IN1 вкл/выкл** |
| `0x9b:0x10` | 0 | **EQ IN2 вкл/выкл** |
| `0x9b:0x12` | 0 | EQ IN1, второй параметр |
| `0x9b:0x13` | 0 | EQ IN2, второй параметр |

Все четыре приходят в одном пакете (`+13633..13639 ms`), подряд.
Диапазон значений пока известен только как «0» — устройство сейчас в
выключенном состоянии EQ.

**Важно:** тегов `0xab:0x0f` (EQ наушников) при старте **не было** —
подтверждает, что 10-полосный EQ наушников доступен только в Pro audio mode.

### 2.7 ЭКВАЛАЙЗЕРЫ (`0x91`..`0x94`) — 40 параметров, по 10 на каждый

Четыре одинаковых блока. Каждый — 10 параметров, судя по значениям,
это пары «gain/freq» для полос:

| тег | значение | тег | значение |
|---|---|---|---|
| `0x91:0x01` | 0 | `0x91:0x06` | 0 |
| `0x91:0x02` | 1 | `0x91:0x07` | 1 |
| `0x91:0x03` | 0 | `0x91:0x08` | 0 |
| `0x91:0x04` | 632 | `0x91:0x09` | 632 |
| `0x91:0x05` | 7000 | `0x91:0x0a` | 7000 |

То же для `0x92`, `0x93`, `0x94`.

**Расшифровка (гипотеза, но очень правдоподобная):**
- `PP 1..5` — полосы 1..5 левого канала
- `PP 6..0a` — полосы 1..5 правого канала
- значения `0, 1, 0, 632, 7000` = **тип фильтра, Q, gain, частота**
  (7000 Гц, 632 — вероятно freq×10 или Q)

Это **5 полос × 2 канала × 4 блока = 40 параметров**. Совпадает с
«10-band PEQ» из мануала.

## 4. ЧЕГО ВСЁ ЕЩЁ НЕТ

- **Микшер** (`Mix A..E`, 10 каналов) — в стартовом пакете **отсутствует**.
  Ни одного тега. Это подтверждает: микшер идёт другим каналом (не HID).
- **Loopback** — нет.
- **48V фантом** — нет в этом пакете.
- **Селекторы источников** (`0x64:0x02`, `0x62:0x02`) — нет (они не читаются).

## 5. КАК ПОВТОРИТЬ

```
# 1) запустить слушатель (он ждёт)
node src/tools/capture-restart.js 30

# 2) в другом окне — жёстко перезапустить MCC
Stop-Process -Name "M Control Center" -Force
Start-Process "C:\Program Files\TOPPING Pro\M Control Center\M Control Center.exe"
```

**Важно:** `CloseMainWindow()` НЕ работает — MCC не закрывается, PID
остаётся. Нужен именно `Stop-Process -Force`.
