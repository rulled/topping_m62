## 3. МИКШЕР — самый богатый набор

### 3.1 Ключи для каналов IN12, AUX, BT, OTGIN, PB12, PB34, PB56, PB78, PB910

**59 ключей на канал.** Для каждой шины `MixA`…`MixC` (в Pro) или `MixA`…`MixE` (в Live):

| ключ | тип | пример | смысл |
|---|---|---|---|
| `Mix<X>_GAIN` | число | `12` | усиление (связанный режим) |
| `Mix<X>_GAINLeft` | число | `0` | усиление левого |
| `Mix<X>_GAINRight` | число | `0` | усиление правого |
| `Mix<X>_Link` | bool | `false` | L/R связаны? |
| `Mix<X>_MUTE` | bool | `false` | мьют (связанный) |
| `Mix<X>_MUTELeft` | bool | `false` | мьют левого |
| `Mix<X>_MUTERight` | bool | `false` | мьют правого |
| `Mix<X>_SOLO` | bool | `false` | соло (связанный) |
| `Mix<X>_SOLOLeft` | bool | `false` | соло левого |
| `Mix<X>_SOLORight` | bool | `false` | соло правого |
| `Mix<X>_ANTI` | bool | `false` | антифаза (связанный) |
| `Mix<X>_ANTILeft` | bool | `false` | антифаза левого |
| `Mix<X>_ANTIRight` | bool | `false` | антифаза правого |
| `Mix<X>_BalanceLinkedLeft` | число | `0` | баланс L в связанном режиме |
| `Mix<X>_BalanceLinkedRight` | число | `100` | баланс R в связанном режиме |
| `Mix<X>_BalanceUnlinkLeft` | число | `50` | баланс L в развязанном |
| `Mix<X>_BalanceUnlinkRight` | число | `50` | баланс R в развязанном |

**ВАЖНО:** это НЕ просто «gain/solo/mute», как я писал раньше.
У каждой клетки матрицы **16 параметров**, включая стерео-развязку
и антифазу.

### 3.2 Особый случай: канал FX

`[Mixer_FX]` имеет только **17 ключей** — без стерео-развязки:
`Mix<X>_GAIN`, `_MUTE`, `_SOLO` на каждую шину. Логично: FX уже стерео.

### 3.3 Шины D и E

У шин `MixD` и `MixE` в файлах **только** `GAIN`, `MUTE`, `SOLO`
(без Left/Right). То есть полная стерео-матрица есть только у A/B/C,
а D/E — упрощённые.

## 4. ЭКВАЛАЙЗЕРЫ — ДВА РАЗНЫХ ФОРМАТА

### 4.1 EQ_IN1 / EQ_IN2 — 4 полосы, формат `|тип|частота|Q|gain|`

```
Eq%401=|0|632|0.7|0
```

| позиция | значение | смысл |
|---|---|---|
| 1 | `0` | тип фильтра |
| 2 | `632` | **частота, Гц** |
| 3 | `0.7` | Q |
| 4 | `0` | gain, дБ |

### 4.2 EQ_HP — 10 полос, ДРУГОЙ формат `тип|gain|частота|Q|?`

```
Eq%401=0|9|35|0.5395|1
Eq%402=0|-4.5|258|0.707|1
Eq%403=0|-4|2891|2.0213|1
Eq%404=0|3.5|4688|1.4552|1
Eq%405=0|6|9355|2.0213|1
Eq%406=0|5|14159|1.1642|1
```

**Формат:** `тип|gain|частота|Q|?`

| позиция | смысл |
|---|---|
| 1 | тип фильтра (0) |
| 2 | **gain, дБ** (9, −4.5, −4, 3.5, 6, 5) |
| 3 | **частота, Гц** (35, 258, 2891, 4688, 9355, 14159) |
| 4 | Q (0.5395, 0.707, 2.0213…) |
| 5 | флаг (1) |

**Это подтверждает:** EQ наушников существует и имеет 10 полос —
но доступен только в **Pro audio mode**.

Обрати внимание на частоты: 35, 258, 2891, 4688, 9355, 14159 —
типичные полосы графического эквалайзера.

### 4.3 Прочие ключи EQ

| ключ | значения | смысл |
|---|---|---|
| `Switch` | `0` / `1` | вкл/выкл |
| `GainInput` | `0` | усиление входа (только IN1/IN2) |
| `GainOutput` | `-10` | усиление выхода (только HP) |
| `Expanded` | `0` | развёрнута ли панель |
| `EQStateTarget/Source/EachFilter/Combined/Filtered` | `0` / `1` | какие графики показывать |
| `EQFilteredType` | `0` | тип отображения |

### 5.3 Реверберация — по режимам

Отдельные наборы для `Studio`, `Live`, `Hall`, `Bypass`:

| ключ | значения |
|---|---|
| `ReverbStudio/Live/Hall/Bypass` | 4 |
| `DryWetStudio` | 30 |
| `DryWetLive` | 30 |
| `DryWetHall` | 30, 25 |
| `DryWetBypass` | 30 |

## 10. ВИДИМОСТЬ ПАНЕЛЕЙ

|---|---|

## 14. ОГРАНИЧЕНИЕ, КОТОРОЕ НАДО ПОМНИТЬ

Инвентаризация показывает, **что существует**, но не доказывает, что
каждый ключ применяется устройством. Проверено на практике только:

- `MixA_GAIN` — пишется при движении слайдера
- `Input_IN1.GAIN` — пишется при перетаскивании dial
- `Input_IN1.48V` — пишется при клике
- `Switch` EQ — при клике

Остальные ключи **наблюдены в файле**, но их влияние на звук
не проверялось поштучно.
